# Himax WiseGuard

Welcome to the official repository for the **Himax WiseGuard Edge AI Sensing Platform**.

WiseGuard is an edge AI sensing platform designed to enable intelligent, low-power, and privacy-aware sensing applications. It combines Himax AI processors, sensing technologies, AI algorithms, firmware, and software tools to support rapid development and deployment of intelligent sensing solutions.

This repository provides official WiseGuard software releases, development resources, reference implementations, and technical documentation.

## Overview

The WiseGuard platform provides an integrated solution for edge AI sensing applications, including:

- Edge AI processing
- Computer vision and AI inference
- Human presence and occupancy sensing
- People detection and tracking
- Intelligent event detection
- Sensor and camera integration
- Embedded firmware and AI algorithms
- Host APIs and application integration

WiseGuard is designed to support a wide range of applications including smart offices, smart buildings, security systems, occupancy management, industrial sensing, and other intelligent edge sensing use cases.
